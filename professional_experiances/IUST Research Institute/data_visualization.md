### Developing a Data Visualization Dashboard for Production Line Insights

At IUST, I developed a comprehensive data visualization dashboard to provide actionable insights into production line performance. The project addressed the need for real-time visibility into manufacturing processes and enabled data-driven decision-making.

My role focused on backend development, where I implemented the core services responsible for collecting, processing and delivering production data. I designed and built a scalable backend architecture with high performance that could handle frequent data updates from many devices while maintaining low latency and high reliability.

I created an automated data pipeline that aggregated data from multiple sources, processed it, and stored it in a PostgreSQL database. I then used Grafana to create interactive visualizations and dashboards that displayed key metrics such as production volume, failure rates, and process efficiency. The dashboard enabled production teams to identify bottlenecks, track trends, and make informed decisions to improve quality and efficiency.

**Technologies used**

* Python
* FastAPI
* PostgreSQL
* SQL
* Grafana
* Docker
* Manufacturing automation

**Business impact**

* Designed and implemented a data visualization dashboard for production line insights.
* Reduced production line downtime by **15%** through real-time monitoring and proactive issue detection.
* Provided production teams with actionable insights that enabled data-driven decision-making.
* Improved production efficiency by identifying bottlenecks and optimizing workflows.
* Enhanced visibility into production processes through interactive visualizations and comprehensive reporting.
